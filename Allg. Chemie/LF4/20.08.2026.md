# 1. Allgemeine und organische Chemie

**Chemie** ist die Wissenschaft von den **Eigenschaften, dem Aufbau und der Umwandlung von Stoffen**.

Dabei untersucht man unter anderem:

* Welche Eigenschaften besitzt ein Stoff?
* Woraus besteht ein Stoff?
* Wie reagieren Stoffe miteinander?
* Welche neuen Stoffe entstehen bei einer Reaktion?

Die Chemie hat sich aus verschiedenen Bereichen entwickelt, z. B.:

* Metallurgie
* Glasherstellung
* Kosmetik und Seifen
* Medikamente
* Farben
* Papierherstellung
* Lederherstellung

---

# 2. Einteilung der Stoffe

Stoffe werden grundsätzlich in **Reinstoffe** und **Stoffgemische** eingeteilt.

## Reinstoffe

Ein Reinstoff besteht nur aus **einer Stoffart**.

### Chemische Elemente

Bestehen nur aus einer Atomsorte.

Beispiele:

* Eisen (Fe)
* Sauerstoff (O)
* Stickstoff (N)

### Chemische Verbindungen

Bestehen aus mehreren verschiedenen Elementen, die **chemisch miteinander verbunden** sind.

Beispiele:

* Wasser (H₂O)
* Kohlenstoffdioxid (CO₂)
* Natriumchlorid (NaCl)

---

# 3. Stoffgemische

Ein Stoffgemisch besteht aus **mindestens zwei verschiedenen Reinstoffen**.

Man unterscheidet:

### Homogene Stoffgemische

Die Bestandteile sind **nicht sichtbar voneinander unterscheidbar**.

Beispiele:

* Salzlösung
* Alkohol + Wasser
* Luft

### Heterogene Stoffgemische

Die Bestandteile sind **voneinander unterscheidbar** oder bilden mehrere Phasen.

Beispiele:

* Sand + Wasser
* Öl + Wasser
* Granit

## Merksatz

**Homogen = überall gleich**

**Heterogen = nicht überall gleich**

---

# 4. Phasen und Phasengrenzfläche

Eine **Phase** ist ein Bereich eines Stoffes bzw. Stoffgemisches, der überall die gleichen Eigenschaften besitzt.

Eine **Phasengrenzfläche** ist die sichtbare oder mit einem Mikroskop erkennbare **Grenze zwischen zwei verschiedenen Phasen**.

### Beispiel: Öl + Wasser

Öl und Wasser vermischen sich nicht dauerhaft.

Es entstehen:

* eine Ölphase
* eine Wasserphase

Die Grenze zwischen beiden ist die **Phasengrenzfläche**.

→ Das Gemisch ist **heterogen**.

### Beispiel: Milch

Milch sieht mit bloßem Auge gleichmäßig aus. Unter einem Mikroskop können jedoch Fetttröpfchen erkannt werden.

→ Milch wird deshalb als **heterogenes Gemisch** betrachtet.

# 5. Zusammensetzung der Luft

Trockene Luft besteht ungefähr aus:

| Stoff                   |         Anteil |
| ----------------------- | -------------: |
| Stickstoff (N₂)         |       **78 %** |
| Sauerstoff (O₂)         |       **21 %** |
| Argon (Ar)              |     **0,93 %** |
| Kohlenstoffdioxid (CO₂) |     **0,04 %** |
| Sonstige Gase           | **ca. 0,01 %** |

Wasserdampf ist **nicht konstant enthalten**. Sein Anteil hängt von Temperatur und Luftfeuchtigkeit ab.

### Merksatz

**78 % N₂ + 21 % O₂ + ca. 1 % Rest**

Luft ist ein **homogenes Gasgemisch**, weil die verschiedenen Gase gleichmäßig verteilt sind.

# 6. Heterogene Stoffgemische

| Aggregatzustände    | Stoffgemisch   | Beispiel                |
| ------------------- | -------------- | ----------------------- |
| fest + fest         | **Gemenge**    | Granit                  |
| fest + flüssig      | **Suspension** | Sand in Wasser          |
| fest + gasförmig    | **Rauch**      | Staub in Luft           |
| flüssig + flüssig   | **Emulsion**   | Milch                   |
| flüssig + gasförmig | **Nebel**      | Wassertröpfchen in Luft |

### Merkhilfe

* **fest + fest → Gemenge**
* **fest + flüssig → Suspension**
* **fest + gasförmig → Rauch**
* **flüssig + flüssig → Emulsion**
* **flüssig + gasförmig → Nebel**

---

# 7. Homogene Stoffgemische

| Aggregatzustände      | Stoffgemisch                  | Beispiel          |
| --------------------- | ----------------------------- | ----------------- |
| fest + fest           | **Legierung / Mischkristall** | Messing           |
| fest + flüssig        | **Lösung**                    | Salz in Wasser    |
| flüssig + flüssig     | **Lösung**                    | Alkohol in Wasser |
| gasförmig + flüssig   | **Lösung**                    | CO₂ in Wasser     |
| gasförmig + gasförmig | **Gasgemisch**                | Luft              |

### Merkhilfe

Bei homogenen Gemischen ist besonders häufig der Begriff **Lösung** wichtig.

**Salz + Wasser → Salzlösung**

**Alkohol + Wasser → Lösung**

**verschiedene Gase → Gasgemisch**

---

# 8. Reinstoff oder Stoffgemisch?

Diese Unterscheidung ist sehr wichtig:

| Stoff           | Einteilung               |
| --------------- | ------------------------ |
| Sauerstoff (O₂) | Reinstoff / Element      |
| Stickstoff (N₂) | Reinstoff / Element      |
| Wasser (H₂O)    | Reinstoff / Verbindung   |
| Salz (NaCl)     | Reinstoff / Verbindung   |
| Salzlösung      | homogenes Stoffgemisch   |
| Luft            | homogenes Stoffgemisch   |
| Granit          | heterogenes Stoffgemisch |
| Öl + Wasser     | heterogenes Stoffgemisch |

**Wichtig:**
Wasser allein ist **kein heterogenes Gemisch**. Reines Wasser ist ein **Reinstoff**.

---
### Aerosol > kurz erklärt

Ein **Aerosol** ist ein **heterogenes Gemisch**, bei dem **feine feste oder flüssige Teilchen in einem Gas** verteilt sind.

Beispiele:

* **Rauch** → feste Teilchen in Luft
* **Nebel** → Flüssigkeitströpfchen in Luft

**Merksatz:**
**Aerosol = kleine Teilchen in einem Gas.**

---

# 9. Die wichtigsten Merksätze

**Reinstoff:** Eine Stoffart.

**Stoffgemisch:** Mehrere Stoffarten.

**Homogen:** Überall gleich, keine sichtbare Phasengrenze.

**Heterogen:** Mehrere Phasen, Phasengrenzen erkennbar.

**Luft:** homogenes Gasgemisch.

**Öl + Wasser:** heterogenes Gemisch.

**Salz + Wasser:** homogene Lösung.

**Granit:** heterogenes Gemenge.

### Die 5 wichtigsten Stoffgemische:

**Gemenge – Suspension – Emulsion – Rauch – Nebel**

Und bei homogenen Gemischen besonders:

**Lösung – Gasgemisch – Legierung**
