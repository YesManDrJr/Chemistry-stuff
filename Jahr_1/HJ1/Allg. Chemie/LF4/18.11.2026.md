# Säure-Base-Chemie

## 1. Formelsammlung

### 1.1 pH- und pOH-Wert

pH = -lg c(H₃O⁺)

pOH = -lg c(OH⁻)

Umgestellt nach der Konzentration:

c(H₃O⁺) = 10^(-pH)

c(OH⁻) = 10^(-pOH)

Zusammenhang:

pH + pOH = 14

---

### 1.2 Stoffmengenkonzentration und Stoffmenge

c = n / V

n = c · V

**Einheiten:**
- c = mol/L
- n = mol
- V = L

---

### 1.3 Stoffmenge und Masse

m = n · M

n = m / M

**Einheiten:**
- m = g
- n = mol
- M = g/mol

---

### 1.4 Massenkonzentration

B = m / V

c = B / M

Umgestellt:

B = c · M

Zusammenhang:

B = n · M / V

B = c · V · M / V

=> c = B / M

---

### 1.5 Massenanteil

w(X) = m(X) / m(Lsg)

Zusammenhang mit Stoffmenge und Dichte:

w(X) = (n · M) / (D · V)

w(X) = (c · M) / D

Grundformeln:

n = m / M

=> m = n · M

D = m / V

=> m = D · V

Umgestellt nach der Konzentration:

c = (w · D) / M

---

## Aufgabe 3 – Masse von NaOH berechnen

**Gegeben:**
- V = 2000 mL = 2 L
- pH = 10,5
- pOH = 14 - 10,5 = 3,5

**Gesucht:**
- m(NaOH)

**1. Konzentration berechnen**

c(OH⁻) = 10^(-3,5)

c(OH⁻) = 3,16 · 10⁻⁴ mol/L

**2. Stoffmenge berechnen**

n = c · V

n(NaOH) = 0,000316 mol/L · 2 L

n(NaOH) = 0,000632 mol

n(NaOH) = 6,32 · 10⁻⁴ mol

**3. Masse berechnen**

m = n · M

m(NaOH) = 0,000632 mol · 39,99719 g/mol

**Ergebnis:**

m(NaOH) = 0,02528 g = 25,3 mg

## Aufgabe 4 – pH-Wert einer KOH-Lösung

**Gegeben:**
- B(KOH) = 0,540 g/L
- M(KOH) = 56,106 g/mol

**Gesucht:**
- pH

**1. Konzentration berechnen**

c = B / M

c(KOH) = 0,540 g/L / 56,106 g/mol

c(KOH) = 0,009624639 mol/L

c(KOH) = 9,62 · 10⁻³ mol/L

**2. pOH berechnen**

pOH = -lg c(OH⁻)

pOH = -lg(9,624 · 10⁻³)

pOH = 2,016

**3. pH berechnen**

pH = 14 - pOH

pH = 14 - 2,016

**Ergebnis:**

pH = 11,98

## Aufgabe 5 – pH-Wert einer NaOH-Lösung

**Gegeben:**
- w(NaOH) = 1,49 %
- D = 1,015 g/mL
- M(NaOH) = 39,99719 g/mol

**Gesucht:**
- pH

**1. Konzentration berechnen**

c = (w · D) / M

Dichte umrechnen:

1,015 g/mL = 1015 g/L

Massenanteil umrechnen:

1,49 % = 0,0149

Einsetzen:

c = (0,0149 · 1015 g/L) / 39,99719 g/mol

c = 0,378114063 mol/L

**2. pOH berechnen**

pOH = -lg c(OH⁻)

pOH = -lg(0,378 mol/L)

pOH = 0,42238

**3. pH berechnen**

pH = 14 - pOH

pH = 14 - 0,42238

**Ergebnis:**

pH = 13,578

## Aufgabe 6 – Masse von HClO₄ berechnen

**Gegeben:**
- V(HClO₄) = 500 mL = 0,5 L
- pH = 2,5
- pOH = 11,5
- M(HClO₄) = 100,4589 g/mol

**Gesucht:**
- m(HClO₄)

**1. Konzentration berechnen**

c = 10^(-pH)

c = 10^(-2,5)

c = 0,003162278 mol/L

**2. Masse berechnen**

m = c · M · V

m = 0,003162278 mol/L · 100,4589 g/mol · 0,5 L

**Ergebnis:**

m ≈ 0,159 g
