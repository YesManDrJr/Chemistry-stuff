## Die 3 Aggregatzustände

### 1. Fest

**Beispiele:** Eis, Stein, Metall

* Teilchen liegen **dicht beieinander**.
* Sie haben **feste Plätze**.
* Sie können nur **schwingen**.
* Der Stoff hat eine **feste Form**.
* Das Volumen bleibt **gleich**.

**Merksatz:**

> Fest = Teilchen dicht + feste Plätze + feste Form

---

### 2. Flüssig

**Beispiele:** Wasser, Öl, Alkohol

* Teilchen liegen noch **relativ dicht beieinander**.
* Sie können sich **aneinander vorbeibewegen**.
* Der Stoff hat **keine feste Form**.
* Er nimmt die **Form des Gefäßes** an.
* Das Volumen bleibt ungefähr **gleich**.

**Merksatz:**

> Flüssig = Teilchen dicht + beweglich + nimmt Gefäßform an

---

### 3. Gasförmig

**Beispiele:** Wasserdampf, Sauerstoff, Luft

* Teilchen sind **weit voneinander entfernt**.
* Sie bewegen sich **frei**.
* Ein Gas hat **keine feste Form**.
* Es hat auch **kein festes Volumen**.
* Es **füllt den vorhandenen Raum** aus.

**Merksatz:**

> Gas = Teilchen weit auseinander + frei beweglich + füllt Raum

---

## Direktvergleich

|          | Fest      | Flüssig                        | Gasförmig        |
| -------- | --------- | ------------------------------ | ---------------- |
| Teilchen | dicht     | dicht                          | weit auseinander |
| Bewegung | schwingen | bewegen sich aneinander vorbei | frei bewegen     |
| Form     | fest      | Gefäßform                      | Gefäßform/Raum   |
| Volumen  | fest      | fest                           | nicht fest       |

## Zustandsänderungen

Wenn ein Stoff von einem Aggregatzustand in einen anderen wechselt, nennt man das **Zustandsänderung**.

| Von → Nach              | Bezeichnung   | Beispiel             |
| ----------------------- | ------------- | -------------------- |
| **fest → flüssig**      | Schmelzen     | Eis → Wasser         |
| **flüssig → fest**      | Erstarren     | Wasser → Eis         |
| **flüssig → gasförmig** | Verdampfen    | Wasser → Wasserdampf |
| **gasförmig → flüssig** | Kondensieren  | Wasserdampf → Wasser |
| **fest → gasförmig**    | Sublimieren   | Feststoff → Gas      |
| **gasförmig → fest**    | Resublimieren | Gas → Feststoff      |

### Einfach merken

**Fest ↔ Flüssig**
→ **Schmelzen / Erstarren**

**Flüssig ↔ Gasförmig**
→ **Verdampfen / Kondensieren**

**Fest ↔ Gasförmig**
→ **Sublimieren / Resublimieren**

### Wichtig

Bei einer Zustandsänderung **bleibt der Stoff derselbe**.

Beispiel:

**Eis → Wasser → Wasserdampf**

Es ist jedes Mal **H₂O**, nur der Aggregatzustand verändert sich.

**Merksatz:**

> Zustandsänderung = Der Stoff bleibt gleich, nur sein Aggregatzustand ändert sich.
