## Atombau und PSE > kurze Zusammenfassung

### 1. Ladungen

* **Proton** → positiv `+`
* **Elektron** → negativ `−`
* **Neutron** → neutral `0`

### 2. Aufbau eines Atoms

Ein Atom besteht aus:

* **Atomkern** → Protonen + Neutronen
* **Elektronenhülle** → Elektronen

Bei einem **neutralen Atom** gilt:
**Anzahl Protonen = Anzahl Elektronen**

### 3. Oktettregel

Atome wollen meistens **8 Elektronen auf ihrer Außenschale** erreichen.

Das erreichen sie, indem sie:

* Elektronen **abgeben**
* Elektronen **aufnehmen**
* oder Elektronen **teilen** (Bindungen)

### 4. Kernladungszahl / Ordnungszahl

Die **Kernladungszahl** bzw. **Ordnungszahl `Z`** gibt an, wie viele **Protonen** ein Atom besitzt.

Beispiel:
**Sauerstoff: Z = 8**
→ 8 Protonen
→ bei einem neutralen Atom auch **8 Elektronen**

Die Ordnungszahl bestimmt, **welches Element** es ist.

### 5. Orientierung im PSE

Im Periodensystem:

* **Ordnungszahl** → Anzahl der Protonen
* **Periode (Zeile)** → Anzahl der Elektronenschalen
* **Hauptgruppe (Spalte)** → Anzahl der Außenelektronen
* **Links** → hauptsächlich Metalle
* **Rechts** → hauptsächlich Nichtmetalle
* **Stufentreppe** → Grenze zwischen Metallen und Nichtmetallen

### Merksatz

**Proton = +**
**Elektron = −**
**Neutron = 0**

**Ordnungszahl = Protonenzahl**

**Periode = Schalen**

**Hauptgruppe = Außenelektronen**

**Oktettregel = möglichst 8 Außenelektronen**
