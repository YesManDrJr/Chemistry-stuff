# Formelsammlung – Gravimetrie

## 1. Feuchtigkeitsgehalt

**Wassergehalt der ursprünglichen feuchten Probe:**

w(H₂O) = m(H₂O) / m(hyg. Probe) · 100 %

**Masse des enthaltenen Wassers:**

m(H₂O) = m(hyg. Probe) − m(xer)

**Feuchtigkeitsgehalt aus dem Trockengehalt:**

w(H₂O) = 100 % − w(xer)

## 2. Trockengehalt

**Trockengehalt in Prozent:**

w(xer) = m(xer) / m(hyg. Probe) · 100 %

**Masse der Trockenmasse:**

m(xer) = m(hyg. Probe) − m(H₂O)

## 3. Massenanteil eines Bestandteils

**Massenanteil bezogen auf die Trockenmasse:**

w(X) = m(X) / m(xer) · 100 %

**Massenanteil bezogen auf die feuchte Probe:**

w(X) = m(X) / m(hyg. Probe) · 100 %

## 4. Zusammenhang zwischen Feuchtigkeits- und Trockengehalt

w(H₂O) + w(xer) = 100 %

## 5. Bedeutung der Formelzeichen

| Zeichen | Bedeutung |
|---|---|
| w | Massenanteil in % |
| m | Masse in g |
| X | Beliebiger Bestandteil |
| H₂O | Wasser |
| hyg. | Feucht |
| xer | Trocken |

**Merke:** Achte immer darauf, ob der Massenanteil auf die feuchte Probe oder auf die Trockenmasse bezogen werden soll. Davon hängt der Nenner der Formel ab.
