# Radikale und radikalische Substitution

## 1. Begriffe

### Radikale
Ein Radikal ist ein Atom oder Molekül, das mindestens ein ungepaartes Valenzelektron besitzt.

- Radikale sind sehr reaktionsfreudig.
- Sie reagieren deshalb häufig sehr schnell mit anderen Teilchen.

### Anionen
- Negativ geladene Ionen.
- Entstehen durch die Aufnahme von Elektronen.

### Kationen
- Positiv geladene Ionen.
- Entstehen durch die Abgabe von Elektronen.

## 3. Herstellung von Halogenalkanen

### Radikalische Substitution

Bei der radikalischen Substitution wird ein Wasserstoffatom eines Alkans durch ein Halogenatom ersetzt.

**Allgemeine Reaktionsgleichung:**

R–CH₃ + Br₂ → R–CH₂Br + HBr

Die Reaktion läuft in drei Schritten ab:

### 1. Startreaktion (Initiation)

Durch Lichteinfluss wird das Brommolekül homolytisch gespalten.

Dabei entstehen zwei Bromradikale.

**Reaktionsgleichung:**

Br–Br → (Licht) 2 Br•

### 2. Kettenreaktionen (Propagation)

Die entstandenen Radikale reagieren miteinander. Dabei entstehen neue Radikale, wodurch die Reaktion immer weiterlaufen kann.

**Schritt 1:**

Ein Bromradikal entreißt dem Alkan ein Wasserstoffatom.

R–CH₃ + Br• → R–CH₂• + HBr

Es entsteht ein Alkylradikal.

**Schritt 2:**

Das Alkylradikal reagiert mit einem Brommolekül.

R–CH₂• + Br₂ → R–CH₂Br + Br•

Es entsteht ein Halogenalkan und ein neues Bromradikal.

Dieses kann erneut eine Kettenreaktion auslösen.

### 3. Abbruchreaktionen (Termination)

Zwei Radikale reagieren miteinander. Dadurch entstehen stabile Moleküle und die Radikalkettenreaktion wird beendet.

**Mögliche Abbruchreaktionen:**

- Bromradikal + Alkylradikal:

  Br• + CH₃• → CH₃Br (Brommethan)

- Bromradikal + Bromradikal:

  Br• + Br• → Br₂

- Alkylradikal + Alkylradikal:

  CH₃• + CH₃• → C₂H₆ (Ethan)
