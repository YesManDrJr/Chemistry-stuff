# Schalenmodell > Grundlagen

Das **Schalenmodell** stellt ein Atom vereinfacht so dar:

```text
        3. Schale (M)
      ┌─────────────┐
      │  3. Schale  │
      │ ┌─────────┐ │
      │ │2. Schale│ │
      │ │ ┌─────┐ │ │
      │ │ │Kern │ │ │
      │ │ └─────┘ │ │
      │ └─────────┘ │
      └─────────────┘
```

Die Elektronen befinden sich auf verschiedenen **Schalen**:

* **K-Schale** = 1. Schale
* **L-Schale** = 2. Schale
* **M-Schale** = 3. Schale
* **N-Schale** = 4. Schale

## Wie werden die Elektronen verteilt?

Die Schalen werden **von innen nach außen** besetzt.

Als einfache Regel:

> **K: 2 | L: 8 | M: 18 | N: 32**

Für einfache Elemente reicht häufig:

> **Erst die innere Schale auffüllen, dann die nächste.**

---

## Beispiel 1: Sauerstoff

Sauerstoff hat die **Ordnungszahl 8**.

→ Ein neutrales Sauerstoffatom besitzt **8 Elektronen**.

Verteilung:

```text
K-Schale: 2
L-Schale: 6
```

Schema:

```text
        L-Schale
      •  •  •  •  •  •
    ┌─────────────────┐
    │    K-Schale     │
    │      •     •    │
    │      KERN       │
    └─────────────────┘
```

Kurz schreibt man:

> **O: 2 | 6**

---

## Beispiel 2: Natrium

Natrium hat die Ordnungszahl **11**.

→ 11 Elektronen

Verteilung:

> **2 | 8 | 1**

Also:

* K = 2
* L = 8
* M = 1

Das letzte Elektron befindet sich auf der **äußersten Schale**.

---

## Beispiel 3: Chlor

Chlor hat die Ordnungszahl **17**.

→ 17 Elektronen

Verteilung:

> **2 | 8 | 7**

Also:

* K = 2
* L = 8
* M = 7

Damit hat Chlor **7 Außenelektronen**.

---

# Zusammenhang mit dem PSE

Das Schalenmodell lässt sich direkt mit dem Periodensystem verbinden:

**Periode = Anzahl der besetzten Schalen**

Beispiel:

> Chlor: **2 | 8 | 7**

Chlor hat **3 besetzte Schalen**.

→ Chlor steht in der **3. Periode**.

**Merksatz:**

> **Periode = Schalen**
> **Hauptgruppe = Außenelektronen**
