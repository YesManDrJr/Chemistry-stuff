## Massenkonzentration

B(x) = m(X) / V
m(x) = B(x) * V

**1g/cm^3 = 1Kg/L**

A2.
geg B1(NaCl) = 283 g/L, B2(NaCl) = 311 g/l, V = 1.50m^3 = 1500 L

ges: m(NaCl)

DELTA_B(NaCl) = 311 g/L - 283 g/L = 28 g/L

m(NaCl) = DELTA_B * V
m(NaCl) = 28 g/L * 1500L = 42.000 g = 42,0 Kg (Signifikanz)

A4.
geg: M(CuSO4) = 159,606g/mol, M(Cu) = 63,55g/mol, m(CuSO4) = 12,5g, V = 12,0L
ges: B(Cu)

n(Cu) = n(CuSO4)
n = m / M

m(Cu) / M(Cu) = m(CuSO4) / M(CuSO4) => m(Cu) = **m(CuSO4) / M(CuSO4) * M(Cu)** = 12.5g / 159,606g/mol * 63,55g/mol = 4,977g

= 4,977g / 2L = 2.488g/L = 2.5g/L
