# TM-Buch – Seite 172

## Aufgabe 5: Volumenanteil

### Gegeben

- ε_min = 1,2 %
- ε_max = 7,5 %
- V_ges = 12,5 m³

### Gesucht

- V_min
- V_max

### Formel

ε(X) = V(X) / V_ges

Nach V(X) umgestellt:

V(X) = ε(X) · V_ges

**Wichtig:** Prozentwerte müssen vor dem Einsetzen in die Formel in Dezimalzahlen umgewandelt werden.

### Mindestvolumen

V_min = ε_min · V_ges

V_min = 0,012 · 12,5 m³

**Ergebnis: V_min = 0,15 m³**

### Maximalvolumen

V_max = ε_max · V_ges

V_max = 0,075 · 12,5 m³

**Ergebnis: V_max = 0,9375 m³**

# TM-Buch – Seite 173

## Aufgabe 3: Stoffmengenanteil

### Gegeben

- m(Essigsäure) = 12,5 g
- m(Wasser) = 100 g
- M(Essigsäure) = 60,05176 g/mol
- M(Wasser) = 18,01488 g/mol

### Gesucht

- x(Essigsäure)
- x(Wasser)

### Gesamtmasse

m_ges = m(Essigsäure) + m(Wasser)

m_ges = 12,5 g + 100 g

**Ergebnis: m_ges = 112,5 g**

### Formel für den Stoffmengenanteil

x(X) = n(X) / n_ges

Die Gesamtstoffmenge ergibt sich aus:

n_ges = n(Essigsäure) + n(Wasser)

### Stoffmenge der Essigsäure

**Formel:**

n = m / M

**Rechnung:**

n(Essigsäure) = 12,5 g / 60,05176 g/mol

**Ergebnis: n(Essigsäure) ≈ 0,20815 mol**

### Stoffmenge des Wassers

n(Wasser) = m(Wasser) / M(Wasser)

n(Wasser) = 100 g / 18,01488 g/mol

**Ergebnis: n(Wasser) ≈ 5,55097 mol**

### Gesamtstoffmenge

n_ges = n(Essigsäure) + n(Wasser)

n_ges = 0,20815 mol + 5,55097 mol

**Ergebnis: n_ges ≈ 5,75912 mol**

### Stoffmengenanteil der Essigsäure

x(Essigsäure) = n(Essigsäure) / n_ges

x(Essigsäure) = 0,20815 mol / 5,75912 mol

x(Essigsäure) ≈ 0,03614

**Ergebnis: x(Essigsäure) ≈ 3,61 %**

### Stoffmengenanteil des Wassers

x(Wasser) = n(Wasser) / n_ges

x(Wasser) = 5,55097 mol / 5,75912 mol

x(Wasser) ≈ 0,96386

**Ergebnis: x(Wasser) ≈ 96,39 %**

### Kontrolle

x(Essigsäure) + x(Wasser) = 100 %

3,61 % + 96,39 % = 100 %
