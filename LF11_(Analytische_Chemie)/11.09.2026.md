# Flammenfärbung verschiedener Kationen

## Grundprinzip

Die **Flammenfärbung** entsteht, wenn Elektronen durch Energiezufuhr auf ein **höheres Energieniveau** gelangen und anschließend wieder zurückspringen.

### Einfaches Beispiel: Satellit

Man kann sich das wie einen Satelliten vorstellen:

* Ein Satellit besitzt Energie und befindet sich auf einer bestimmten Umlaufbahn.
* Bekommt er **mehr Energie**, kann er auf eine **höhere Umlaufbahn** gelangen.
* Gibt er diese Energie wieder ab, kehrt er auf seine ursprüngliche Umlaufbahn zurück.

Bei Elektronen ist es ähnlich:

**Energiezufuhr → Elektron springt auf ein höheres Energieniveau → Elektron springt zurück → Licht wird abgegeben**

## Beispiel: Barium

Barium besitzt **2 Valenzelektronen**.

1. Barium wird in der Flamme **erhitzt**.
2. Durch die Wärme bekommen die Außenelektronen **Energie**.
3. Ein Elektron gelangt dadurch auf ein **höheres Energieniveau**.
4. Nach sehr kurzer Zeit springt es wieder zurück.
5. Dabei wird **Licht** abgegeben.
6. Das Licht erzeugt die typische **Flammenfärbung** von Barium.

**Barium → fahlgrüne / blassgrüne Flammenfärbung**

**Wellenlänge:** ca. **512–524 nm**

## Merksatz

> **Energie rein → Elektron hoch → Elektron zurück → Licht raus → Flammenfarbe**
