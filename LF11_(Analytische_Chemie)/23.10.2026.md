## Mehr zur Gravimetrie

Die Gravimetrie ist ein Analyseverfahren bei dem die masse und der Massentanteil von Stoffen mittels wiegen bestimmt wird.

- Feuchtigkeitsgehalt
- Trockenmassengehalt
- Glühruckstandsbestimmung
- Anteile von extrahierbaren Stoffen

Anteil Feuchtigkeit und anteil Feststoff = 100%

w(H2O) = m(H2O) / m(hyg)

w(xer) = m(xer) / m(hyg)

xer = xeros, trocken
hyg = hygroskopisch, feucht
---

1. geg: m,hyg(Koks) = 10,824g, m(H2O) = 0,682g

w(H2O) = 0,682g / 10,824g = 0,06300813 = 6.30%

w,xer = 10,824g - 0,682g / 10,824g = 0,93699187 = 93.70%
---

2. geg: m,hyg(Pigment) = 5,4563g, m(xer) = 5,4123g

n(xer) = 5,4563g - 5,4123g = 0,044g
w(xer) = 5,4563g / 5,4123g = 0.81%
---

3. geg: m,hyg(Pigment) = 4,308g, m,xer = 2,835g

w,xer = 2,835 g / 4,308g = 0,658077994 = 65.8%
w(H2O) = 4,308g - 2,835g / 4,308g = 0,341922006 = 34.19%
---

4. geg: m,hyg(farbstoff) = 10,4561g, (H2O) = 1,7542g

w(H2O) = 1,7542g / 10,4561g = 0,167768097 = 16.77%
w,xer = 10,4561g - 1,7542g  / 10,4561g = 0,832231903 = 83.22%
---

5. geg: w(H2O) = 7.35%, m,hyg(Kohle) = 8.254g

w,xer = 100 - 7,35 = 92,65g
m,xer = 92,65g * 8,254g = 7,647g

## Arbeitsschritte zur Bestimmung von w,xer und w(H2O)

1. Probegefäß trocknen und leer wiegen > m(leer)
2. Einwiegen der Probe auf 1mg genau > m,hyg
3. Trocknen im Trockenschrank bei 105°C > Verdampfen flüchtiger Bestandteile
4. Abkühlen im Exsikkator
5. Bedingung > w,xer und w(H20)

Wenn zwei aufeinander folgende Wägungen einen Unterschied von weniger als 10mg aufweisen ist die Massenkonstant erreicht
