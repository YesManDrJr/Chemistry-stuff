# Isomerie

**Isomerie** bedeutet:

> Stoffe haben die **gleiche Summenformel**, aber einen **unterschiedlichen Aufbau**.

Dadurch können sie unterschiedliche Eigenschaften haben.

Beispiel:

> **C₄H₁₀** → Butan und 2-Methylpropan
> gleiche Summenformel, aber unterschiedlich aufgebaut → **Isomere**

---

# Isomere der Alkane

Je mehr Kohlenstoffatome ein Alkan besitzt, desto mehr verschiedene Isomere kann es geben.

## Butan – C₄H₁₀

Butan besitzt **2 Isomere**:

1. **Butan**

   ```text
   C — C — C — C
   ```

2. **2-Methylpropan**

   ```text
       C
       |
   C — C — C
   ```

→ **2 Isomere**

---

## Hexan – C₆H₁₄

Hexan besitzt **5 Isomere**:

1. **Hexan**
2. **2-Methylpentan**
3. **3-Methylpentan**
4. **2,2-Dimethylbutan**
5. **2,3-Dimethylbutan**

→ **5 Isomere**

---

## Heptan – C₇H₁₆

Heptan besitzt **9 Isomere**:

1. **Heptan**
2. **2-Methylhexan**
3. **3-Methylhexan**
4. **2,2-Dimethylpentan**
5. **2,3-Dimethylpentan**
6. **2,4-Dimethylpentan**
7. **3,3-Dimethylpentan**
8. **3-Ethylpentan**
9. **2,2,3-Trimethylbutan**

→ **9 Isomere**

---

## Für den Test merken

| Alkan  | Summenformel | Anzahl Isomere |
| ------ | ------------ | -------------: |
| Butan  | C₄H₁₀        |          **2** |
| Hexan  | C₆H₁₄        |          **5** |
| Heptan | C₇H₁₆        |          **9** |

**Merksatz:**

> **Gleiche Summenformel + anderer Aufbau = Isomere.**

Und wichtig: **Butan → 2**, **Hexan → 5**, **Heptan → 9**.
