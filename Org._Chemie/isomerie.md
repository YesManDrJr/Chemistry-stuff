# Isomerie

**Isomerie** bedeutet:

> Stoffe haben die **gleiche Summenformel**, aber einen **unterschiedlichen Aufbau**.

Dadurch können sie unterschiedliche Eigenschaften haben.

Beispiel:

> **C₄H₁₀** → Butan und 2-Methylpropan
> gleiche Summenformel, aber unterschiedlich aufgebaut → **Isomere**

---

# Isomere der Alkane

Je mehr Kohlenstoffatome ein Alkan besitzt, desto mehr verschiedene Isomere kann es geben.

## Butan – C₄H₁₀

Butan besitzt **2 Isomere**:

1. **Butan**

   ```text
   C — C — C — C
   ```

2. **2-Methylpropan**

   ```text
       C
       |
   C — C — C
   ```

→ **2 Isomere**

---

## Hexan – C₆H₁₄

Hexan besitzt **5 Isomere**:

1. **Hexan**
2. **2-Methylpentan**
3. **3-Methylpentan**
4. **2,2-Dimethylbutan**
5. **2,3-Dimethylbutan**

→ **5 Isomere**

---

## Heptan – C₇H₁₆

Heptan besitzt **9 Isomere**:

1. **Heptan**
2. **2-Methylhexan**
3. **3-Methylhexan**
4. **2,2-Dimethylpentan**
5. **2,3-Dimethylpentan**
6. **2,4-Dimethylpentan**
7. **3,3-Dimethylpentan**
8. **3-Ethylpentan**
9. **2,2,3-Trimethylbutan**

→ **9 Isomere**

**Merksatz:**

> **Gleiche Summenformel + anderer Aufbau = Isomere.**

## Beispiele

### 1. 2,4-Dimethyl-4-ethylhexan

* **Hexan** → längste Hauptkette: 6 C
* **2,4-Dimethyl** → je eine CH₃-Gruppe an C2 und C4
* **4-Ethyl** → eine C₂H₅-Gruppe an C4

Vereinfacht:

```text
        CH3
         |
CH3–CH–CH2–C–CH2–CH3
             |
           CH2–CH3
```

---

### 2. 3,3,5-Trimethyloctan

* **Octan** → Hauptkette: 8 C
* **3,3,5-Trimethyl** → drei CH₃-Gruppen
* zwei davon an C3
* eine an C5

```text
        CH3
         |
CH3–CH2–C–CH2–CH–CH2–CH2–CH3
         |      |
        CH3    CH3
```

---

### 3. 2,2,4-Trimethyl-3-ethylhexan

* **Hexan** → Hauptkette: 6 C
* **2,2,4-Trimethyl** → drei CH₃-Gruppen
* **3-Ethyl** → eine C₂H₅-Gruppe an C3

```text
       CH3
        |
CH3–C–CH–CH–CH2–CH3
    |  |   |
   CH3 CH2–CH3
        |
       CH3
```

### So liest du solche Namen immer:

**Zahl + Gruppe → Position der Gruppe**

Beispiel:

**2,4-Dimethyl**

→ CH₃ an **C2** und **C4**

**4-Ethyl**

→ C₂H₅ an **C4**

**3,3,5-Trimethyl**

→ CH₃ an **C3, C3 und C5**

**Merksatz:**

> **Hauptkette zuerst → Nummern anschauen → Seitenketten an die angegebenen Stellen setzen.**
