Wärme = Q = 1 Joule, J
Masse = m = 1 kg
spezifische wärmekapazität = c = 1 KJ / kg*K
temparatur änderung = Delta T = 1 Kelvin

Q = m * c * Delta T
Q = 2m * c * Delta T (Wenn masse gegen ursprung wert verdoppelt wird und andere größen konstant hält, verdoppelt sich die wärme)

Q~m (Q proportional zu m)

1/2 Q = Delta T * c / 2m
---

1. geg: Q = 8400J, c = 4.19 KJ/K*Kg, V1 = 20°C, V2 = 25°C

ges: m

Delta T = 5°C

m = Q / c * Delta T
m = 8400J / 4.19 KJ/K*Kg * 5°C = 401g
---

2. geg: Q = 4,5KJ, c = 0,9 KJ/K*Kg, m = 250g
ges: Delta T

Delta T = m * c / Q
Delta T = 250g * 0.9 KJ/K*Kg / 4.5KJ
Delta T = 20°C
